# ClauLi

**Настольный аксессуар, который следит за вашей сессией Claude Code вместо вас.**

> [English version](README.md)

ClauLi — аппаратный монитор на базе ESP32, отображающий персонажа с роботизированными глазами на небольшом цветном экране. Цвет ореола, настроение глаз и статистика на экране обновляются в реальном времени, отражая загруженность сессии Claude Code и недельный расход токенов. Python-демон для macOS/Linux/Windows читает OAuth-токен Claude Code, опрашивает Anthropic API и передаёт данные на устройство по Bluetooth Low Energy.

## Возможности

- **3 персонажа на выбор** — ClauLi (по умолчанию), Pixl и Old-TV, каждый со своим визуальным стилем.
- **Живые эмоции и анимации** — 7 настроений глаз (нейтральный, любопытный, сонный, встревоженный и другие) сменяются на случайном таймере 20 с–10 мин; анимация моргания работает непрерывно.
- **Градиент по % использования** — глаза и ореол плавно переходят из зелёного в жёлтый и красный по мере роста недельного расхода токенов от 0 % до 100 %.
- **8 вариантов отображения статистики** — `none`, `bezel_orbit`, `twin_columns`, `hud_ribbon`, `tear_pearls`, `corner_chip`, `ecg_monitor`, `classic` — выберите подходящий.
- **Часы** — демон передаёт текущую метку времени и часовой пояс; между опросами устройство ведёт время самостоятельно. Доступны несколько стилей отображения.
- **Настраиваемый текст** — показывать ничего, процент, обратный отсчёт до сброса лимита или оба значения.
- **BLE-соединение** — подключение по Bluetooth Low Energy без сопряжения; демон автоматически переподключается с экспоненциальной задержкой.
- **Веб-конфигуратор** — одностраничный интерфейс на `http://localhost:8765`: персонаж, раскладка, часы, цветовые точки, текстовый режим, ориентация, анимации по статусу — всё в реальном времени без перепрошивки.
- **Язык RU / EN** — переключается в веб-интерфейсе или долгим нажатием кнопки на устройстве; выбор сохраняется в NVS и переживает перезагрузки.
- **Обновление прошивки по воздуху** — загрузите новый `firmware.bin` через веб-интерфейс (Настройки → Обновление прошивки); USB-кабель после первой прошивки не нужен.

## Аппаратная часть

| Компонент | Описание |
|---|---|
| Плата MCU | Любой ESP32-C6, ESP32-S3, ESP32-C3 или ESP32. Эталон: **NanoESP32-C6 v1.0** |
| Дисплей | **ST7789V2** 240×280, SPI |
| Среда сборки по умолчанию | `esp32c6` (см. `firmware/platformio.ini`) |

### Распиновка (ESP32-C6, проверенная конфигурация)

| Сигнал | GPIO |
|---|---|
| LCD MOSI | 10 |
| LCD SCLK | 23 |
| LCD CS | 5 |
| LCD DC | 4 |
| LCD RESET | 6 |
| LCD Подсветка | 7 |
| Кнопка BOOT | 9 |
| Кнопка A | 7 |
| Кнопка B | 6 |

Остальные поддерживаемые чипы (ESP32-S3, ESP32, ESP32-C3) и примерные значения пинов перечислены в `firmware/platformio.ini`. Значения для не-C6 плат — ориентировочные; проверьте их по схеме своей платы и при необходимости отредактируйте `build_flags` нужного env.

## Быстрый старт

### 1. Сборка и прошивка

**Необходимо:** [PlatformIO CLI](https://platformio.org/install/cli) — `pip install platformio`.

Сборка для ESP32-C6 (по умолчанию):

```bash
scripts/build.sh
```

Сборка и прошивка через USB одной командой (порт определяется автоматически):

```bash
scripts/build.sh --upload
```

Только прошивка (после предыдущей сборки):

```bash
scripts/flash-esp32c6.sh                        # автоматический поиск порта
scripts/flash-esp32c6.sh /dev/cu.usbmodemXXXX   # явное указание порта
```

Как найти серийный порт:

```bash
ls /dev/cu.usbmodem*           # macOS
ls /dev/ttyACM* /dev/ttyUSB*   # Linux
```

После первой USB-прошивки последующие обновления можно загружать по воздуху через веб-интерфейс (Настройки → Обновление прошивки).

### 2. Установка и запуск демона

#### Вариант А — Скачать готовый бинарник из релиза (проще всего)

Последний релиз доступен на странице [GitHub Releases](https://github.com/MrSedek/ClauLi/releases):

| Платформа | Файл | Как запустить |
|---|---|---|
| macOS | `ClauLi-macOS.zip` | Разархивировать, перенести `ClauLi.app` в `/Applications`, открыть двойным щелчком. При первом запуске: правая кнопка → Открыть, чтобы обойти Gatekeeper. |
| Linux x86_64 | `clauli-linux-x86_64.tar.gz` | `tar xzf clauli-linux-x86_64.tar.gz && ./clauli/clauli --tray` |
| Windows x86_64 | `ClauLi-windows-x86_64.zip` | Разархивировать, запустить `clauli.exe --tray`. При запросе SmartScreen нажать *Подробнее → Выполнить в любом случае*. |

#### Вариант Б — Запуск из исходников

Требуется Python 3.10+. Скрипт автоматически создаёт venv и устанавливает зависимости:

```bash
scripts/run-daemon.sh               # передний план, язык — English (по умолчанию)
scripts/run-daemon.sh --lang ru     # передний план, русский язык
scripts/run-daemon.sh --port 8888   # нестандартный порт
```

Для запуска в фоне используйте обёртку из `daemon/`:

```bash
cd daemon
./daemon.sh start                   # фон; логи → ~/.config/claude-usage-monitor/daemon.log
./daemon.sh stop
./daemon.sh status
./daemon.sh logs -f
```

#### Вариант В — macOS launchd-агент (автозапуск при входе)

```bash
scripts/install-daemon-macos.sh              # английский, порт 8765
scripts/install-daemon-macos.sh --lang ru    # русский
scripts/install-daemon-macos.sh --port 8888  # нестандартный порт
```

Скрипт устанавливает plist-агент LaunchAgent, создаёт venv и немедленно загружает его. Логи: `~/Library/Logs/clauli.{out,err}.log`.

### 3. Открыть веб-конфигуратор

После запуска демона откройте в браузере:

```
http://localhost:8765
```

Здесь можно выбрать персонажа, раскладку, стиль часов, цветовые точки, режим текста, ориентацию и язык. Все изменения отправляются на устройство в реальном времени по BLE.

## Принцип работы

```
Anthropic API
      |
      | (OAuth, опрос каждые 60 с)
      v
  Python-демон  ──── BLE GATT (без сопряжения) ────>  ESP32
  (порт 8765)                                           ST7789V2 240x280
      |
      ^
  Браузер  <────  http://localhost:8765
```

1. Демон опрашивает Anthropic API каждые 60 секунд (внутренний цикл тикает каждые 5 с для быстрого обнаружения BLE-отключений).
2. Формируется компактный JSON-пакет — счётчики токенов, проценты, метка времени, часовой пояс и визуальная конфигурация — и записывается в GATT RX-характеристику устройства по BLE.
3. Прошивка распаковывает пакет, обновляет цвет и настроение персонажа и перерисовывает экран.
4. Веб-конфигуратор (обслуживается встроенным aiohttp-сервером демона) позволяет настраивать все визуальные параметры без перепрошивки.

## OAuth / повторная аутентификация

Демон читает OAuth-токен Claude Code из **macOS Keychain** (имя сервиса `Claude Code-credentials`) и записывает нужные файлы учётных данных в `~/.config/anthropic/`. На Linux и Windows токен нужно задать через `claude setup-token` или экспортировать переменную окружения.

**Если в логе демона появляется `invalid_grant` / `Refresh token not found or invalid`:**

- **Повторный вход (рекомендуется):** откройте приложение Claude Code или выполните `claude` в терминале и пройдите авторизацию. Демон перечитывает Keychain при каждом опросе и восстанавливается автоматически — следите за строкой `AUTH: recovered` в логе.
- **Безголовый вариант:** выполните `claude setup-token`, затем экспортируйте токен перед запуском демона:

```bash
export CLAUDE_CODE_OAUTH_TOKEN=<ваш-токен>
scripts/run-daemon.sh
```

- **Проверить запись в Keychain (macOS):**

```bash
security find-generic-password -s "Claude Code-credentials" -w \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['claudeAiOauth']['expiresAt'])"
```

Веб-интерфейс также показывает уведомление о необходимости повторного входа при истёкшем токене.
